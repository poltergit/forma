# FORMA brand assets

These SVGs are proposed Phase 04 identity assets, not final approved artwork.

## Files
- `forma-mark.svg`: standalone Modular Frame concept.
- `forma-lockup.svg`: horizontal lockup for light surfaces.
- `forma-lockup-reversed.svg`: horizontal lockup for dark surfaces.
- `forma-favicon.svg`: simplified standalone symbol.

## Use
- Preserve aspect ratio.
- Do not recolor individual parts independently.
- Use the reversed lockup only on sufficiently dark backgrounds.
- The SVG wordmark references Space Grotesk Semibold; font rendering can vary until the wordmark is converted to reviewed outlines.
- The favicon is a draft and must be checked in browser tab sizes and at 16 px.

See `docs/HYBRID_IDENTITY_SYSTEM.md` for rationale and approval criteria.
